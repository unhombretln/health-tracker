# 🚀 Инструкция по публикации

## Быстрый старт с GitHub Pages

### Шаг 1: Создание репозитория
1. Зайдите на https://github.com
2. Нажмите **New repository** (зелёная кнопка)
3. Заполните:
   - **Repository name**: `health-tracker` (или любое другое)
   - **Description**: "Веб-приложение для анализа тренировок"
   - **Public** ✅ (чтобы использовать бесплатный GitHub Pages)
   - **Add README**: не ставьте галочку (мы загрузим свой)
4. Нажмите **Create repository**

### Шаг 2: Загрузка файлов
1. На странице репозитория нажмите **Add file** → **Upload files**
2. Перетащите эти файлы:
   - `index.html` (главная страница приложения)
   - папки `css` и `js` (стили и код приложения)
   - `README.md` (описание проекта)
3. В поле "Commit message" напишите: `Initial commit`
4. Нажмите **Commit changes**

### Шаг 3: Включение GitHub Pages
1. Перейдите в **Settings** (вкладка вверху)
2. В левом меню найдите **Pages**
3. В разделе **Source** выберите:
   - **Branch**: `main`
   - **Folder**: `/ (root)`
4. Нажмите **Save**
5. Подождите 1-2 минуты

### Шаг 4: Готово! 🎉
Ваше приложение доступно по адресу:
```
https://ваш-username.github.io/health-tracker
```

## Альтернативные варианты

### Netlify (ещё проще!)
1. Зайдите на https://netlify.com
2. Нажмите **Add new site** → **Deploy manually**
3. Перетащите в окно браузера папку проекта (с `index.html`, `css` и `js`)
4. Готово! Сайт опубликован за 30 секунд

### Vercel
1. Зайдите на https://vercel.com
2. Нажмите **Add New** → **Project**
3. Импортируйте репозиторий с GitHub
4. Deploy!

### Cloudflare Pages
1. Зайдите на https://pages.cloudflare.com
2. **Create a project**
3. Подключите GitHub репозиторий
4. Deploy!

## Собственный домен

Если хотите использовать свой домен (например, `health.yourdomain.com`):

### Для GitHub Pages:
1. В настройках Pages добавьте **Custom domain**
2. В DNS вашего домена добавьте CNAME запись:
   ```
   health.yourdomain.com → your-username.github.io
   ```

### Для Netlify/Vercel/Cloudflare:
Следуйте инструкциям в настройках проекта - они проведут через весь процесс.

## Обновление приложения

Когда захотите обновить приложение:

### Через веб-интерфейс GitHub:
1. Откройте нужный файл в репозитории: `index.html` (разметка), `css/styles.css` (оформление) или файл в папке `js` (код)
2. Нажмите иконку карандаша (Edit)
3. Вставьте новый код
4. **Commit changes**

### Через git (для продвинутых):
```bash
git clone https://github.com/your-username/health-tracker.git
cd health-tracker
# Внесите изменения в index.html, css/ или js/
git add .
git commit -m "Update app"
git push
```

## Проверка работы

После публикации проверьте:
- ✅ Страница загружается
- ✅ Можно загрузить TCX/GPX файлы
- ✅ Графики отображаются
- ✅ Профиль сохраняется
- ✅ Работает на мобильных устройствах
